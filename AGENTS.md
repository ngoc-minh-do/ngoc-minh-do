# AGENTS.md

**GitHub profile README repo.** No build, test, lint, or deploy steps.

## Structure

- `README.md` — profile content (markdown). Edit freely.
- `profile/` — static SVG stats cards generated by the [`github-readme-stats-action`](https://github.com/stats-organization/github-readme-stats-action) workflow (`.github/workflows/update-cards.yml`) using the repo secret `GH_PAT` (scopes `repo` + `read:user`). Do not edit card image paths in `README.md` to remote URLs.
- `.github/workflows/update-cards.yml` — daily cron + manual dispatch; regenerates cards, commits, pushes.

## Commands

No project commands exist. No package manager, no CI, no scripts.
